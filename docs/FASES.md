# Fases del proyecto

## Fase 0: reinicio

Se crea una base mínima del proyecto para definir el repositorio, la estructura inicial y la estrategia de despliegue.

- Configuración básica del repositorio
- Página web inicial de arranque
- Documentación de fases
- Configuración de despliegue para AWS Amplify

## Fase 1: shell TypeScript responsive

- Estado: implementada
- Objetivo: construir una base tipada y adaptable para móvil, tablet y escritorio.
- Entregable: aplicación Vite en `src/main.ts`, paleta institucional, navegación colapsable, pestañas de producto, buscador, tarjetas de recomendación y navegación móvil.
- Criterio de salida: `npm run build` correcto, commit publicado y vista confirmada en Amplify.

## Fase 2: contenido de aprendizaje

- Estado: implementada, pendiente de publicación
- Objetivo: crear la primera tarjeta de actividad y su interacción.
- Entregable: actividad de biomecánica con cuatro respuestas, estados correcto/incorrecto y feedback inmediato.
- Criterio de salida: interacción funcional, build correcto y commit publicado.
